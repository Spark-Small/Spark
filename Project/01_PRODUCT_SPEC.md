> 行为需求的精简规格。细节 FR 表仍可对照历史 `Docs/PRD.md`；**冲突以本文件 + 代码为准**。

---

## 1. 产品定义

| 项 | 内容 |
|----|------|
| 名称 | 坐标系 |
| 品类 | 同城一起玩：活动（场）+ 搭子（人）+ 消息履约 |
| 主转化 | 发现 → 读懂 → 参加 / 预约 → 群 / 凭证 |

## 2. 角色

| 角色 | 目标 | 主路径 |
|------|------|--------|
| 参加者 | 找到可跟的局 | 活动 Tab → 详情 → 参加 |
| 发起人 | 发局、管名额、改期 | 发起 → 管理 → 群 |
| 找搭子 | 找人玩 / 预约 | 搭子 Tab |
| 履约中 | 行程、群、凭证 | 我的行程 / 消息 |

---

## 3. 功能范围（按模块）

### 3.1 认证（必须）

- 硬登录墙：未登录不可进 Tab  
- 短信 / Apple；（微信仅 SDK 配置后展示）  
- 协议同意；版本 bump 时已登录用户重签  
- 兴趣标签硬门槛（无跳过）  
- 欢迎意图 Sheet（可跳过，≠ 兴趣）

### 3.2 活动（核心）

- 发现货架、筛选、下一场摘要 Banner  
- 详情 Form：决策卡、行程/费用/须知、相关推荐  
- 参加 / 候补 / 转正 / 取消；冲突提示  
- 发起 / 编辑 / 主办管理（名额、改期、取消）  
- 本机订单与钱包结账（Release 诚实披露）  
- Zoom 进详情；活动群入口  

**产品诚实声明**：目录与写操作在软启动期可为本地快照；对外文案不得暗示「已全网实时报名」除非 `09` 标明远程已开。

### 3.3 搭子 / 消息 / 广场 / 我的

- 搭子：免费发现 / 预约商业化（供给未就绪时 Release 空态诚实）  
- 消息：私聊、活动群；Release 无自动回复伪装  
- 广场：分享与活动关联（可并入活动 Tab 生命周期）  
- 我的：资料、兴趣、核验、行程凭证、钱包、设置  

### 3.4 信任与合规

- 报名 / 预约 / 社交前：认证照 + 人脸核验（`IdentityAccessGate`）  
- 行为信用账本（非星级墙）；对外信任档案为**已点亮奖章墙** + 近 90 天事实（无空态说教文）  
- Privacy Manifest、可外开隐私/条款 URL  

---

## 4. 非功能需求

| 项 | 要求 |
|----|------|
| 平台 | iOS 26.5+，SwiftUI |
| 无障碍 | Dynamic Type、系统按钮 label、Reduce Motion/Transparency |
| 诚实门控 | Release 无假外部支付成功、无假充值、无静默演示报名 |
| 持久化 | 写失败可见（横幅）；禁止 silent 覆盖用户数据 |
| 性能 | 发现货架可缓存；首帧登录不解码全量目录（细则 `19`） |
| 文案 | 主路径走 `*Copy`；演进见 `20` |
| 可维护 | PR DoD / Flag 生命周期见 `21` |

---

## 5. 验收口径（产品层）

| ID | 场景 | 通过标准 |
|----|------|----------|
| P-01 | 未登录 | 仅登录页，无 Tab |
| P-02 | 登录成功 | 兴趣完成后进活动 Tab |
| P-03 | 免费参加（已核验） | 成功 Sheet；可进行程 / 群 |
| P-04 | Release 付费 | 仅钱包；披露本地账本；无假 Apple Pay 到账 |
| P-05 | 发起活动 | 预览诚实「待补充」；发布后本地可见 |
| P-06 | 取消登录会话 | 回登录页，拆掉主界面模型 |

正式「全网报名 / 真支付」验收见 `16` 阻塞项，不在此列为已交付。  
单屏契约见 `17`。
