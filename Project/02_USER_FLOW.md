# 02 · 用户流程（User Flow）

> 实现门闸以 `ContentView` 为准。心理层旅程可参考历史 `Docs/UserJourneyTechControl.md`（≠ 实现清单）。

---

## 1. 冷启动 / 会话（全局）

```
启动
 ├─ 已登录 && 需重签协议 → LegalConsentGate →（同意）
 ├─ 未登录 → LoginView（短信 / Apple / 微信*）
 ├─ 已登录 && AppModel 未就绪 → 启动屏占位
 └─ 已登录 && 就绪
      ├─ 未完成兴趣 → InterestOnboardingView（硬门，无跳过）
      └─ TabView
           └─ 未看过欢迎 → 强制活动 Tab + 半屏欢迎 Sheet（可跳过）
```

\* 微信：SDK 未配置时 **不展示**入口。

**规则**：兴趣 ≠ 欢迎；协议勾选独立于登录主按钮。

---

## 2. 参加者：发现 → 参加

```
活动 Tab
 → 浏览货架 / 筛选
 → Zoom 或 Push 详情
 →（可选）私信发起人 / 看成员 / 地图
 → 主 CTA 参加
      → IdentityAccessGate（认证照 + 人脸）未过则打断
      → JoinConfirm（冲突 / 须知 / 付费则结账）
      → Success Sheet：**主 CTA「我的行程」**；次要日历 / 活动群（不并列抢主）
```

候补：满员 → 候补 → 放名额通知 → 转正（付费需已支付或再结账）。

取消参加：未支付直接取消；已支付走退款申请态（Release 不假装秒退完）。

---

## 3. 发起人：发布 → 管理

```
活动 Tab 「发起」
 → Compose（封面 / 基础 / 费用 / 简介）
 → Publish Preview（待补充清单诚实）
 → 发布成功 Sheet（主 CTA 打开活动群）
 → 详情 / HostManage（名额、改期、完善说明、取消活动、打开群）
```

取消活动：确认 Dialog；付费订单进入退款策略。

---

## 4. 履约中

```
「我的 → 我的活动」点进单场 →「活动行程 / 凭证」（checklist + 票面同一页）
 → 活动群（消息；行程内或成功 Sheet 次要入口）
 → 结束后轻反馈 / 可选复盘发帖
```

履约 checklist **只在单场行程**；「我的」根**不**挂待办 Form；**不**挂独立「我的订单」（账单→钱包，催办→通知，做事→活动/陪玩）；活动行程含支付/退款商务条；陪玩凭证展开页承接待支付/履约/退款状态机；活动 Tab **不**挂底栏行程附件。  
「我的 → 我的活动」：右上角 Menu 文字按钮（当前分类）+ 横卡（页边/卡距对齐活动发现竖列）；库合集含**已报名 / 候补 / 我发起**；角标与活动卡 `ActivityCardStatus` 看齐（已参加 / 已候补 / 已结束 / 我发起的）；报名点进单场行程，发起进详情。
「我的 → 我的陪玩」：右上角筛选图标 Menu（对齐搭子）+ 双列人像小卡（图下两行）；角标用 `BookingOrderStatus` 产品词；点进预约凭证展开页；空态 CTA 切搭子并打开**约陪玩**页。
单场「活动行程」下一步：双列四件套（约陪玩可选 / 进入群聊 / 导航前往 / 到场签到）；运动户外等类目有蓝图内容时追加装备要求 / 注意事项（进详情）；结束后反馈 / 复盘。
活动邀约与交易催办写入「我的 → 通知」站内收件箱，不挂「我的活动」平行订单页。

---

## 5. 搭子 / 预约（摘要）

```
搭子 Tab（免费 | 预约）
 → 人卡 → 详情
 → 打招呼 / 邀约活动 / 预约下单
 →（预约）确认 → 支付策略 → 履约记录
```

Release：无 SampleData 人设交易；供给空则空态，不伪装接单。

---

## 6. 异常流（必须可恢复）

| 场景 | 行为 |
|------|------|
| JWT 失效 | 登出 → LoginView |
| Apple 凭证撤销 | 冷启动检测后登出 |
| 持久化写失败 | 横幅 + 可理解文案，不吞错 |
| 远程目录失败 | 保留本地；不整包清空 |
| 支付外部通道未接 | 仅钱包 + 披露文案；`useRemoteWallet` 默认关，真到账前不开放远程充值 |
| 充值 | DEBUG 可本机演示；远程 Flag 开且后端通时走微信/支付宝意图；否则「暂不可用」 |
| 提现 / 开票 | 诚实未开放，不发起真实出款/发票 |
