# 02 · 用户流程（User Flow）

> 实现门闸以 `ContentView` 为准。心理层旅程可参考历史 `Docs/UserJourneyTechControl.md`（≠ 实现清单）。

---

## 1. 冷启动 / 会话（全局）

```
启动
 ├─ 已登录 && 需重签协议 → LegalConsentGate →（同意）
 ├─ 未登录 → LoginView（短信 / Apple / 微信*）
 ├─ 已登录 && AppModel 未就绪 → 启动屏占位
 └─ 已登录 && 就绪
      ├─ 未完成兴趣 → InterestOnboardingView（硬门，无跳过）
      └─ TabView
           └─ 未看过欢迎 → 强制活动 Tab + 半屏欢迎 Sheet（可跳过）
```

\* 微信：SDK 未配置时 **不展示**入口。

**规则**：兴趣 ≠ 欢迎；协议勾选独立于登录主按钮。

---

## 2. 参加者：发现 → 参加

```
活动 Tab
 → 浏览货架 / 筛选
 → Zoom 或 Push 详情
 →（可选）私信发起人 / 看成员 / 地图
 → 主 CTA 参加
      → IdentityAccessGate（认证照 + 人脸）未过则打断
      → JoinConfirm（冲突 / 须知 / 付费则结账）
      → Success Sheet → 我的行程 / 群 / 日历
```

候补：满员 → 候补 → 放名额通知 → 转正（付费需已支付或再结账）。

取消参加：未支付直接取消；已支付走退款申请态（Release 不假装秒退完）。

---

## 3. 发起人：发布 → 管理

```
活动 Tab 「发起」
 → Compose（封面 / 基础 / 费用 / 简介）
 → Publish Preview（待补充清单诚实）
 → 发布成功 Sheet
 → 详情 / HostManage（名额、改期、完善说明、取消活动、打开群）
```

取消活动：确认 Dialog；付费订单进入退款策略。

---

## 4. 履约中

```
下一场 Banner（仅欢迎已完成且有真实下一场；无场次不挂发现引导）
 → 我的行程（checklist / 凭证）
 → 活动群（消息）
 → 结束后轻反馈 / 可选复盘发帖
```

履约 checklist **只在行程**，不回活动 Tab 首屏堆待办卡；活动 Tab **不**挂底栏行程附件。

---

## 5. 搭子 / 预约（摘要）

```
搭子 Tab（免费 | 预约）
 → 人卡 → 详情
 → 打招呼 / 邀约活动 / 预约下单
 →（预约）确认 → 支付策略 → 履约记录
```

Release：无 SampleData 人设交易；供给空则空态，不伪装接单。

---

## 6. 异常流（必须可恢复）

| 场景 | 行为 |
|------|------|
| JWT 失效 | 登出 → LoginView |
| Apple 凭证撤销 | 冷启动检测后登出 |
| 持久化写失败 | 横幅 + 可理解文案，不吞错 |
| 远程目录失败 | 保留本地；不整包清空 |
| 支付外部通道未接 | 仅钱包 + 披露文案 |
