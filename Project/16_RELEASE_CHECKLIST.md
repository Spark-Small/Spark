# 16 · 上线验收清单（Release Checklist）

> 分两档：**软启动联调** vs **App Store 正式提审**。不要混为一谈。

---

## A. 软启动（登录 + 活动 UX）— 可做

### A1 登录

- [ ] Release 或 DEBUG+远程：短信登录拿 JWT，杀进程仍登录  
- [ ] 协议 Gate、兴趣硬门、欢迎可跳过  
- [ ] 远程失效 / Apple 撤销 → 回登录  
- [ ] 微信未配置时无按钮  

### A2 活动 UX（本机真相可接受）

- [ ] 未登录无活动 Tab  
- [ ] 发现 / 详情 / Zoom / Form 可用  
- [ ] 参加 / 候补 / 发起 / 主办改期（本地）  
- [ ] Release 支付仅钱包 + 披露文案，无假外部到账  
- [ ] 无自定义 Toast；空错态可读  

### A3 工程门禁

- [ ] `check-imports.sh` 通过  
- [ ] Domain 相关测试通过  
- [ ] Privacy Manifest 与真实 API 粗核对  

---

## B. App Store 正式提审 — 仍阻塞则不可勾「完成」

| # | 阻塞 | 完成标准 |
|---|------|----------|
| 1 | 真支付 PSP | 可选外部方式真实到账；或产品改为纯线下并文案一致 |
| 2 | 活动写 API | 报名/发起等默认走远程且与 `user.id` 一致 |
| 3 | 活动目录 | Release `useRemoteCatalog` + 关 bootstrap 或明确空供给 |
| 4 | 搭子供给 | 非 Sample 交易数据 |
| 5 | IM / APNs | 真消息通道 |
| 6 | Apple 服务端校验 | 登录票服务端闭环 |
| 7 | 微信正式 SDK | 若保留入口 |
| 8 | 托管隐私页 | 公网 HTTPS 可达 |
| 9 | 基线 git tag | 提审包可追溯 |

> **B4 未勾完成。** 客户端已就绪：`discoverCatalog` 契约 + Merge + 空态映射 + 读 Flag；勾完成需后端/运营下发真人发现目录且 Release 可见非 Sample 供给。

---

## C. 客户端诚实门控（已落地 · 回归勿回退）

- [ ] 无访客主路径  
- [ ] Release 无演示码默认  
- [ ] Release 无假外部支付成功 / 假充值  
- [ ] Release 无静默演示报名种子  
- [ ] 活动远程目录不整包覆盖本地  
- [ ] 搭子远程 snapshot 不整包覆盖本地  
- [ ] 履约 checklist 不回活动首屏  

---

## D. 提审前人工

- [ ] 真机走通 A 矩阵  
- [ ] 截图与审核备注与诚实门控一致  
- [ ] 编译与抽检（需要时再 `xcodebuild`）  
- [ ] a11y 抽检（`13` §7）  
- [ ] Privacy Manifest / 分析 SDK 用途与 `14`/`18` 一致  

---

## E. 正式发布运营（App Store 档）

| 项 | 要求 |
|----|------|
| 基线 | git tag + 构建号可追溯（B.9） |
| 分阶段发布 | 优先 Phased Release；观测崩溃与登录漏斗（`18`） |
| 回滚 | 保留上一 tag 构建；Flag 可关的新远程能力优先用 Flag 止血 |
| 崩溃率 | 提审后定团队阈值（如崩溃自由会话）；未接崩溃平台前不写虚假 SLA |
| TestFlight | 外测组跑 A 矩阵 + 付费披露文案；备注写清「本地活动账本」若仍适用 |
| 元数据 | 截图/描述不声称未接能力（真支付、全网报名、真 IM） |

**AI / 工程清 B**：一会话只推进一个 B#；未达完成标准不得勾选；流程见 [21 §7](21_ENGINEERING_WORKFLOW.md)。

## 客观结论（写给决策者）

| 目标 | 是否就绪 |
|------|----------|
| 内部软启动：验登录 + 活动交互 | **可以**（接受本地活动账本） |
| App Store：完整成局商业闭环 | **不可以**，直到 B 表清零 |
